# Binary Search on Answer

An algorithmic paradigm for finding optimal values in monotonic predicate search spaces avoiding 32-bit integer overflow.

---

## Solved Paradigms
- Capacity to ship packages within $D$ days.
- Split array largest sum into $K$ subarrays.
- General `binarySearchFirstTrue` monotonic template.

---

## Complexities
- **Time Complexity:** $O(N \cdot \log(\text{Range}))$
- **Space Complexity:** $O(1)$
