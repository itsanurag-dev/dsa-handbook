# Flexible Multi-Stack in a Single Array

Implements $K$ flexible stacks within a single shared array of capacity $N$ using a free-slot linked list.

---

## Complexities

| Operation | Time Complexity | Space Complexity |
| :--- | :---: | :---: |
| **Push** | $O(1)$ | $O(1)$ |
| **Pop** | $O(1)$ | $O(1)$ |
| **Peek** | $O(1)$ | $O(1)$ |
